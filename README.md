# 🎮 Pac-Man Game — Assembly Language

A classic Pac-Man-inspired game developed using Assembly Language, demonstrating low-level programming concepts, modular code organization, game logic, and interactive gameplay.

## 📌 Project Overview

This project recreates the core experience of the classic Pac-Man arcade game using Assembly Language. It is organized into multiple source files, each responsible for a specific part of the game's functionality.

The project provides practical experience in low-level programming, program flow, data management, and interactive game development.

## ✨ Features

- 🎮 **Game Logic:** Implements the core game flow and gameplay mechanics.
- 👻 **Ghost Management:** Includes a dedicated module for ghost-related behavior.
- 🧩 **Menu System:** Organizes the game's menu functionality.
- 🔊 **Sound Module:** Includes code for game audio functionality.
- 🏆 **Score Management:** Includes a file for storing Pac-Man scores.
- 🛠️ **Modular Architecture:** Separates game functionality into multiple Assembly source files.

*Features may vary depending on the final implementation in each source file.*

## 🛠️ Technologies Used

- **Assembly Language** — Core game implementation
- **Assembly Source Files (`.asm`)** — Modular program structure
- **Text File Storage (`.txt`)** — Score data storage

## 📁 File Descriptions

| File | Purpose |
|---|---|
| `main.asm` | Main program entry point |
| `game.asm` | Core game logic |
| `data.asm` | Game data and related definitions |
| `menu.asm` | Menu-related functionality |
| `ghosts.asm` | Ghost-related logic |
| `sound.asm` | Sound-related routines |
| `utils.asm` | Utility procedures and helper routines |
| `pacman_scores.txt` | Score storage file |

## 🚀 Getting Started

1. Clone or download this repository.
2. Identify the assembler and runtime environment required by the source code.
3. Open the project files in a compatible Assembly Language development environment.
4. Assemble and link the source files according to the project's dependencies.
5. Run the resulting program in the appropriate environment.

The exact setup depends on the Assembly dialect, assembler, and graphics or runtime libraries used in the project. Confirm these requirements from the source code before running it.
